- **WireGuard** — VPN سبک و پایدار
- **SSH tunnel / reverse SSH** — ساده، بدون نصب اضافه
- **FRP** — reverse proxy برای سرویس‌های پشت NAT
- **Cloudflare Tunnel** — اگر دامنه Cloudflare دارید
